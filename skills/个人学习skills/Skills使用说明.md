# Skills安装与使用

此分享套装包含5个Skill及文档模板。先解压总包，再把里面的5个ZIP上传到支持Skill安装的ChatGPT工作环境，发送下面这段话：

请安装这5个压缩包中的全部Skill，保留各自名称，并检查文档整理与制作中的assets和references是否完整。安装完成后逐项告诉我结果。如果当前环境不支持安装，请明确说明，不要把读取文件说成安装成功。

总包只是便于转发的容器；里面每个ZIP才是一个完整的Skill安装包，不要只上传其中的SKILL.md。如果某个客户端不能同时接收5个包，逐个上传并安装即可。

| 安装包 | 作用 |
| --- | --- |
| 回复格式.zip | 自然连贯中文、完整讲解单元、遵守用户指定的交付形式 |
| 文档整理与制作.zip | 文档分类、版本管理、模板选择、导出检查与保存 |
| 后端八股讲解.zip | 依据使用者题库讲解机制，整理面试口述答案 |
| 项目面经.zip | 依据真实代码和记录组织项目回答、技术决策与排查过程 |
| 算法题讲解.zip | 变量定义、原理推导、实例推演和最小代码纠错 |

文档Skill已附带Word学位论文模板、厦大Beamer完整资源、最小Typst作业骨架和讲义PDF视觉样本。Beamer保留原许可证。Typst骨架与Beamer未在本次打包中编译；实际制作时需检查字体、XeLaTeX或Typst等工具。没有附带或授权访问原作者的个人账户、文件路径、学习记录、项目代码、研究数据及原始八股题库。对方需自行提供自己的题库、项目材料和保存位置。

模板是默认参考，可由使用者自己的模板覆盖。其他学校的论文应采用其学校要求。安装后可直接说“用算法题讲解解释这题”或“用文档整理与制作整理这份材料”；具体能否自动调用取决于当前环境支持。
