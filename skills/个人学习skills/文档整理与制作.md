# 文档整理与制作

## 任务范围与优先级

先确认内容任务、交付形式及是否需要文件。用户本次要求优先，普通语言遵循“回复格式”，领域内容遵循对应教学或项目skill。本skill只统一内容整理、排版、模板资源、导出验证与保存，不复制领域教学步骤或研究进度。

用户只要聊天答案、LaTeX或Typst代码时，直接在普通对话给完整内容或代码块，不创建附件、不默认导出PDF、不重复询问。用户要实际文档时按下述流程执行。

## 内容整理

读完指定材料并核对题号、章节及附件。可以合并重复表述，不能删独立知识点、必要推导、条件、追问或代码。保留用户已确认顺序和标记。区分原文事实、补充解释、推断与待核验事项，不编造数值、经历或运行状态。仅排版任务不擅自改写正文。

## 模板选择与资源

先读 [模板绑定与选择](references/templates.md)，按实际任务选一种：

| 文档类型 | 使用规则 |
| --- | --- |
| 学习讲义、八股、项目面经、算法笔记 | 复习讲义模板，以绑定的后端八股PDF为主样本 |
| 正式毕业论文 | 原《学位论文模板.docx》，沿用实际样式和版心 |
| 普通正文报告 | 按用途选A4正文规范，不自动套学位论文封面与声明 |
| 数学、计量与量化课程作业 | 最小Typst作业模板，学生简答格式 |
| 开题、组会和其他学术汇报演示 | 用户上传的厦大Beamer模板，16:9横屏 |

只在讲义模板中默认第一页为独立可跳转目录、第二页开始正文，无额外封面或总结尾页。正式论文按原模板处理目录与前置页；普通报告只有用户要求时添加目录；作业不加封面目录；演示不套A4、论文行距或讲义目录规则。

标题、正文、字体、字重、页眉页脚及配色只在本skill的模板参考中维护；后端与项目skill不再另存一份。使用真实模板或当前样本，不凭“像某个预览”的描述猜字体参数。数学公式保持正常数学字重，不跟随正文全加粗。

## 表格、公式、代码与图片

- 文档和作业优先三线表，避免全框线；跨页重复表头，核对列宽、单位和数值。
- 公式先定义符号，保留必要推导，禁止用方框或 `\boxed{}` 突出公式、结论。不能为排版省略关键条件。
- 代码可复制，保留缩进和必要注释。Typst公式须用Typst语法，不能直接粘贴LaTeX数学命令。
- 图片保持比例，图注紧邻；必要源码、数据和图片相对路径匹配。用户未要求的预览图不作正式交付。
- 用户原文连贯时忠实排版，不额外加标签、速查表、总结页或低价值算例填充篇幅。

## Typst课程作业

默认按用户要求在对话给完整可替换的 `main.typ`，不默认生成PDF。只保留题号与必要小题号，不设封面、大标题或背景说明；答案须准确覆盖全部题目，保留必要模型假设、计算与结论。使用 `assets/coursework.typ` 的A4、11pt、两端对齐和三线表设置，实际作业内容替换注释。

若用户明确要第二种解法，调整实质思路并保持正确性，不只替换措辞。涉及回测、模拟和数据分析，实际计算后再写数值。

## 演示文稿

沿用厦大Beamer的品牌、版式与比例，按内容安排留白、字号和图表，不把论文整页缩小贴进幻灯片。不默认堆小字、多层列表或装饰框。用户要连续汇报时讲稿连续组织，不加入导师提问。

Beamer默认交付TeX与演示PDF；用户只要对话代码时仅给代码块，明确主文件、依赖和XeLaTeX编译方式，不另附文件。不把PDF称为原生可编辑PPTX。需要原生PPTX时使用当前演示工具并说明转换边界。

## 验证与交付

需要生成文件时，核对实际存在、大小和格式完整性，并按可用工具执行编译、渲染和视觉检查。检查中文字体、长公式表格、标题孤行、溢出和异常留白；可跳转目录检查真实链接与书签，不能只看蓝字。字体缺失先查替代并如实说明，不声称使用了未安装字体。

仅输出对话代码时做语法、依赖和完整性检查；不能实际编译时说明未验证，不为了检查而擅自上传文件。对Word/PDF等实际成品调用对应制作skill的验证流程。

## 保存位置与版本管理

凡创建、更新、导出、保存或整理文件，先检索当前使用者实际拥有的文件及目录。采用使用者本次指定的保存位置；已有文件优先更新原身份。没有确认过目录时，根据任务提出最小合理位置，必要时询问，不能把示例路径当作已存在的目录。资料库路径与操作系统路径分别识别，不混用。

按论文、课程、科研项目、技术学习、Skill等实际主题归类，不预设使用者就读学校、课程名称、项目名称或顶层文件夹。不自行建立整套目录；无关材料保持原位置。若当前环境没有相应存储能力，如实说明可交付的位置，不宣称已保存至使用者账户。

### 执行与验收

1. **实际目录优先。** 用户已改名或移动时沿用当前位置，不按过期路径另建一套。先查文件再设计结构，不凭聊天印象声称资料存在。不擅自增加顶层分类，不使用01、02等数字前缀，不建立空的预设子文件夹。
2. **更新原文件。** 同一材料使用稳定名称和原文件身份更新，不生成修正版、最终版、完整版、最新版、(1)等并排副本。PDF与对应Markdown、LaTeX、Typst源码算同一套，一起更新并归位；必要的配套图片、数据、代码同样保留在对应主题。
3. **每套笔记只保留最新版本。** 根据用户最后确认、内容完整性和生成时间确定当前成品；不以补充材料、完整推导或追溯价值为由擅留被新版替代的分章旧稿、预览、旧源码和重复压缩包。原始课件、不同论文、不同作业是独立材料，分别保留。仅在用户明确要求时保留多版。
4. **先验证再清理。** 确认新成品内容完整且保存成功，再依据用户授权将明确被替代的独立旧副本移入回收站。不要仅因时间较早就删除唯一数据、独立代码或其他材料；替代关系不清时先读内容核实，不能核实则保留并说明。不额外清除原文件的平台版本历史。
5. **归档用于其他材料。** 不属于其余类别的文件放归档；已被替代的重复文件按用户授权清理，不再塞进项目里的历史版本。不要借本次更新搬动无关材料或既有历史记录。
6. **中间产物留在临时工作区。** 预览、排版检查图、缓存和测试输出不上传为正式资料。只保存成品、对应源码与必要资源；用户明确要求的图片或测试报告除外。
7. **完成前核对位置与版本。** 检查每个成品的真实路径、名称、身份和配套资源，确认没有留下本次应清理的独立旧版，再报告完成。不把检索无结果视为不存在的充分证据，也不把未执行的保存说成已完成。

修改已安装个人Skill时执行skill-creator的验证与保存流程；普通文件夹里的Skill说明文件本身不等于已安装Skill。用户明确要求同时更新说明文件时，更新原文件，不新增重复规范。不能宣称已修改全局自定义指令或保证所有其他对话自动执行；只报告实际完成的设置。


执行顺序：确认任务与交付形式、实际路径和模板；核对材料；制作；按交付类型验证；更新原文件并检查配套资源与旧版；交付。

## 分享版资源和首次使用

实际模板随本Skill的assets目录提供。优先按references/templates.md中的相对路径读取，不依赖原作者账户或文件标识。模板选择是默认值，使用者新提供的学校模板、样本和本次要求优先。首次实际输出前确认字体及编译工具可用；缺少工具时说明限制。

## 配套规则可用性

本套共5个Skill，建议一并安装。引用其他配套Skill时按其规范名定位；若尚未安装，不声称已调用，不因此阻塞当前可独立完成的内容，必要时说明缺少的模板或能力。
