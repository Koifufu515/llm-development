    """取该会话的 Agent、config 和当前 State（只读快照）

    四类 flow 每次要读写状态机都要这三步（建 agent → 拼 config → 取快照），
    抽成一个函数后调用方一行搞定：agent, config, state = await get_agent_and_state(conv_id)
    """
    from app.agents.handoffs.travel_agent import create_travel_agent
    agent = await create_travel_agent()
    config = {
        "configurable": {"thread_id": conversation_id},
        "recursion_limit": 60,   # 抬高 LangGraph 默认递归上限（默认 25），避免长回合被掐断
    }
    snap = await agent.aget_state(config)
    return agent, config, dict(snap.values or {})

def duration_to_minutes(text: str) -> int:
    """历时 HH:mm → 分钟（自动模式代选排序用）

    容错：解析失败返回大数，让这条候选在按耗时排序时自然排到最后（既不崩、也不会被误选为最优）
    """
    try:
        hh, _, mm = str(text or "").partition(":")
        return int(hh) * 60 + int(mm)
    except Exception:
        return 10 ** 6

def leg_signature(legs: Sequence[Any]) -> str:
    """
    段对象只要有 from_ / to / travel_date 三个属性即可（高铁、航班、自驾的 XxxLeg 都满足），
    所以用鸭子类型接收，不绑定具体类型。
    """
    # ★ 鸭子类型：有 from_ / to / travel_date 三个属性就行
    return "|".join(f"{leg.from_}→{leg.to}@{leg.travel_date}" for leg in legs)

"""
两种缓存（泛型，四类共用）：

- PayloadCache：提交侧候选缓存——查询侧下发卡片时 store，提交侧校验时 get，比对"选的在不在候选里"；
- SignatureCache：段签名查询缓存——同一批段第二次访问直接复用，避免重复打外部服务。

两者都用 Generic[T] 参数化 Payload 类型（TrainMultiSegmentPayload / HotelMultiSegmentPayload…），
一套代码装四种 payload，类型检查器还能帮你查错。
"""
from typing import Callable, Generic, Optional, TypeVar

from app.utils.logger import app_logger

# 泛型 T：某个 capability 的 Payload 类型
T = TypeVar("T")

class PayloadCache(Generic[T]):
    """提交侧候选缓存：按 cache_key（= conversation_id）分桶，多会话并发互不污染"""

    _DEFAULT_KEY = "_"

    def __init__(self, name: str):
        self.name = name
        self._data: dict[str, T] = {}

    def get(self, cache_key: Optional[str] = None) -> Optional[T]:
        """取某会话最近下发的候选；不存在返回 None"""
        return self._data.get(cache_key or self._DEFAULT_KEY)

    def store(self, payload: T, cache_key: Optional[str] = None) -> None:
        """写入本会话的候选（供后续提交侧校验）"""
        self._data[cache_key or self._DEFAULT_KEY] = payload

class SignatureCache(Generic[T]):
    """段签名查询缓存：同一会话、同一批段第二次访问直接复用，避免重复打外部服务

    is_complete 回答"这份 payload 值不值得缓存"，定义权交给调用方，四类的口径并不相同：
    - 高铁：每一段都有候选才缓存——某段偶发为空若被缓存，用户重试会永远命中这份空快照（"空段死锁"）；
    - 航班 / 自驾 / 住宿：只要有一段有结果就缓存——没有机场码之类的段本来就查不出来，重试也没用。
    容量超过 capacity 时，踢掉最早写入的一条。
    """

    def __init__(self, name: str, capacity: int = 32):
        self.name = name
        self.capacity = capacity
        self._data: dict[str, T] = {}

    def _make_key(self, conversation_id: str, sig: str) -> str:
        return f"{conversation_id}#{sig}"

    def get(
            self,
            conversation_id: str,
            sig: str,
            is_complete: Callable[[T], bool] = lambda _p: True,
    ) -> Optional[T]:
        """取缓存：命中且 is_complete 判定通过才复用（不通过当没命中，留给重试）"""
        cached = self._data.get(self._make_key(conversation_id, sig))
        if cached is None:
            return None
        # ★ 读：不值得复用的当没命中，留给重试
        if not is_complete(cached):
            app_logger.debug(f"[{self.name}] 缓存命中但不完整，不复用")
            return None
        app_logger.info(f"🎯 [{self.name}] 命中段签名缓存")
        return cached

    def store(
            self,
            conversation_id: str,
            sig: str,
            payload: T,
            is_complete: Callable[[T], bool] = lambda _p: True,
    ) -> None:
        """写入缓存：只有 is_complete 判定通过才写"""
        # ★ 写：值不值得缓存由调用方的 is_complete 决定（高铁 all，其余三类 any）
        if not is_complete(payload):
            app_logger.warning(f"⚠️ [{self.name}] payload 不值得缓存，不写签名缓存（留给下次重试）")
            return
        self._data[self._make_key(conversation_id, sig)] = payload
        if len(self._data) > self.capacity:      # 简单容量控制：超过时踢掉最早写入的一条
            self._data.pop(next(iter(self._data)))

# 天气查询对象词。★ 缺了这张表，"明天福州天气怎么样"会被当成闲聊交给裸模型乱答。
#   ★ 必须收"不含天气二字"的口语问法（多少度/冷不冷/带伞…），否则用户换个说法就漏判；
#     单字"冷/热/雨"一律不收——"冷门景点""热干面""雨季"会被误伤
WEATHER_OBJECTS = frozenset({
    "天气", "气温", "温度", "降雨", "下雨", "下雪", "台风", "空气质量",
    "多少度", "几度", "冷不冷", "热不热", "冷吗", "热吗", "凉快", "降温", "升温",
    "带伞", "伞", "湿度", "风力", "穿衣", "穿什么", "紫外线", "雾霾", "暴雨",
    "雷阵雨", "晴天", "阴天", "多云", "防晒",
})
# "天气之外的第二诉求"信号词：命中才把非天气部分交回模型补答，纯天气问句不加赘述。
# ★ 不能收裸"怎么"——"天气怎么样"是标准问法，收它会误判成有第二诉求
EXTRA_ASK_WORDS = frozenset({
    "适合", "好玩", "值得", "推荐", "要不要", "能不能", "建议",
    "安排", "路线", "门票", "美食", "景点", "必去", "逛街",
    "怎么玩", "怎么走", "怎么去", "怎么安排", "怎么办",
})
QUERY_VERBS = frozenset({"查", "搜", "问", "看看", "有没", "还有", "多少"})
# 出现这些词说明用户要的是"行程规划"而不是单点查询——对象词放宽后靠它挡回去
PLANNING_NOISE = frozenset({
    "规划", "行程", "攻略", "预算", "人数", "自由行", "安排", "旅行天数",
    # ★ 裸"玩/游玩/旅游/旅行"必须收：对象词放宽到"高铁"之后，
    #   "我想坐高铁去杭州玩，明天的"会凑齐"对象词 + 日期词"，全靠这几个词挡回规划通道
    "玩", "游玩", "怎么玩", "旅游", "旅行",
})
# 相对日期词与天数偏移（长词在前：匹配"大后天"不能被"后天"截胡）
DAY_OFFSET = (("大后天", 3), ("后天", 2), ("明天", 1), ("明日", 1), ("今天", 0), ("今日", 0))
DATE_WORDS = frozenset(w for w, _ in DAY_OFFSET)

# 自动确认表单（前端模板固定文案，去空白后比对）
AUTO_CONFIRM_WORDS = ("全程交给AI自动确认", "无需逐步询问")

# 纯确认语：整句削掉首尾空白与结尾标点后，恰好等于其中一个词才算
CONFIRM_WORDS = frozenset({
    "满意", "可以", "确认", "确定", "对的", "对", "是的", "是", "嗯",
    "好的", "好", "好嘞", "行", "中", "没问题", "就这样", "就这个", "OK", "ok", "Ok",
})
CONFIRM_TAIL = "。！!…,.，、"

# 回退意图：phrases = 单独出现即算；pairs = (左边任一) 与 (右边任一) 同时出现才算
BACK_INTENT = {
    "destination": {
        "phrases": ("重新选", "重选", "选别的", "选另一个", "选其他",
                    "别的地方", "不想去", "选错了", "换一下"),
        "pairs": ((("换", "改"), ("目的地", "城市", "地方")), (("不去",), ("了",))),
    },
    "transport": {
        "phrases": ("重新选", "不坐", "不乘", "换一个", "换一下"),
        "pairs": ((("换", "改", "坐", "乘", "还是"),
                   ("交通", "高铁", "动车", "火车", "飞机", "航班", "自驾", "驾车", "车")),),
    },
    "requirement": {
        "phrases": ("重新规划", "从头", "重新来", "重新开始", "全部重来", "重新选"),
        "pairs": (),
    },
}

# 住宿降级轮的"委托语"：用户把选择权交回给系统
HOTEL_ACCEPT_WORDS = frozenset({
    "按推荐来", "按你的推荐", "你决定", "你看着办", "听你的",
    "都可以", "都行", "随便", "随便选", "无所谓",
})

def _hit(text: str, words) -> bool:
    """这句话里出现过词表里的任意一个词"""
    return any(w in text for w in words)

@dataclass(frozen=True)
class UserIntent:
    """一句话的意图快照。一次扫描算完，下游读字段，不再各自 search"""

    text: str
    auto_confirm: bool = False          # 表单勾了"全程交给 AI 自动确认"
    is_confirm_reply: bool = False      # 整句是一句纯确认语
    train_object: bool = False          # 提到了车票/车次类对象
    flight_object: bool = False         # 提到了航班类对象
    weather_object: bool = False        # 提到了天气类对象
    extra_ask: bool = False             # 天气问句里还夹着"天气之外"的诉求
    query_verb: bool = False
    date_word: bool = False
    planning_noise: bool = False        # 像"规划行程"而不是单点查询
    hotel_accept: bool = False          # 住宿轮的委托语
    back: dict = field(default_factory=dict)   # key -> 是否表达了回退意图

    @property
    def transport_object(self) -> bool:
        """提到任何交通查询对象（车票或航班）"""
        return self.train_object or self.flight_object

    @property
    def looks_like_query(self) -> bool:
        """像"单点班次查询"：对象词 +（动词 或 日期词），且不含规划噪声

        ★ 这就是直查通道的门禁①②，现在只有这一处定义。
          放宽对象词的风险由 planning_noise 接住："明天坐高铁去上海旅游"不会被抢走
        """
        return (self.transport_object
                and (self.query_verb or self.date_word)
                and not self.planning_noise)

    def wants_back(self, key: str) -> bool:
        """用户这句话有没有表达『换 / 改 / 重新选』的意图"""
        return bool(self.back.get(key))

def detect_intent(text: str) -> UserIntent:
    """一次扫描产出意图快照。纯字符串判定，0ms，不调任何模型"""
    raw = str(text or "")
    flat = "".join(raw.split())          # 去掉全部空白，供表单快筛用
    core = raw.strip().rstrip(CONFIRM_TAIL).rstrip()
    back = {}
    for key, cfg in BACK_INTENT.items():
        # ★ 独立短语命中即算；否则要"动作词 × 对象词"共现
        back[key] = _hit(raw, cfg["phrases"]) or any(
            _hit(raw, left) and _hit(raw, right) for left, right in cfg["pairs"]
        )
    return UserIntent(
        text=raw,
        auto_confirm=_hit(flat, AUTO_CONFIRM_WORDS),
        is_confirm_reply=core in CONFIRM_WORDS,
        train_object=_hit(raw, TRAIN_OBJECTS),
        flight_object=_hit(raw, FLIGHT_OBJECTS),
        query_verb=_hit(raw, QUERY_VERBS),
        weather_object=_hit(raw, WEATHER_OBJECTS),
        extra_ask=_hit(raw, EXTRA_ASK_WORDS),
        date_word=_hit(raw, DATE_WORDS),
        planning_noise=_hit(raw, PLANNING_NOISE),
        hotel_accept=_hit(raw, HOTEL_ACCEPT_WORDS),
        back=back,
    )
