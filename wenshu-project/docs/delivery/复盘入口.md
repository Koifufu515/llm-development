# 文枢复盘入口

按一条正常请求连续追踪：web/lib/api → auth与chat → Harness Intent/Rewrite/Retrieve/Answer/Verify → pi → Qwen → 引用与事实回填 → Redis工作记忆/Mongo事件/用户与组织及策略记忆 → Trace/反馈 → Stream异步Worker → Loop Observe/Reflect/Adapt/Deploy/Evaluate。

再重演真实边界：名单不可给学生；失效文件不可用旧缓存；错误来源编号重写两次后只返回原文；新Skill沙箱不达标不可发布；人为格式纠正经审核后改变下一轮输出；进程kill后队列接管；Mongo选主和Redis Sentinel切换；本机扩容超过资源时为什么错误率上升。

阅读reports中的输入、样本数、失败条目、模型usage和估算成本。140项助手回归、脚本模拟审核与合成回放不等于本人已掌握或真实用户效果。后续以你能解释链路、预测故障、修改行为并验收为学习完成标准。
