# 数据来源、范围与复现

## 固定知识库

来源仓库：https://github.com/wikivoyage/wikivoyage.github.io 。来源页面按每篇正文的`source_url`逐条保留，例如https://en.wikivoyage.org/wiki/Suzhou 。署名为Wikivoyage contributors，历史资料按CC BY-SA 3.0标注与归属。导入脚本：`scripts/import_open_pois.py`。

本机原CSV：`data/full_sources/wikivoyage-listings-en.csv`，83236598字节，SHA256：`463abf453da58b89f30bf30d4a251307905e77ad3cf0519af740a1ac66f03b71`。

筛选见脚本中的40个城市候选前缀；实际得到39城、71个来源文章组、966条去重see/do景点活动描述。仅导入有足够正文的记录，不导入旧餐厅/酒店表项及独立价格、营业时间、电话等字段。正文历史描述仍可能过时，不能依靠字段过滤就声称资料都是最新的。

清洗正文：`data/full_guides/wv-*.json`，404025字元。各文件保留城市、原文标题、来源URL、归属、许可、采集时间、正文hash、时效说明。`retrieved_at`只是本次取得的时间；已知lastEdit至2016，不能当2026年更新。`import-report.json`给出真实数量与原始文件hash。

父块1000、重叠200；子块200、重叠50。实际654父块、3120子块；模型text-embedding-v2，1536维，Chroma目录`data/full_rag/chroma`，集合版本`82743fa72fa86b29597c16e0`。重建命令：`PYTHONPATH=. uv run --frozen python scripts/build_full_rag.py`。Redis只缓存可重建的检索结果，key含数据版本和查询策略。

交付包包含清洗正文、归属与索引，省略83MB原始CSV。复现清洗时应从来源仓库取得相同快照并核对SHA；快照不同必须生成新的导入报告，不能沿用本次数量。

## 实时资料

- 高铁：12306-mcp 0.3.10只读查询，启动应用已核验的上车日期补丁。每个交通段保留查询日期、查询时间与来源。
- 航班：Variflight多机场时刻与城市票价并发查询；只将明确关联同一航班号的经济舱报价融合，不将整条航线最低价复制给各班。
- 自驾/地点/照片/步行：高德；名称不匹配不放坐标，GCJ02到地图坐标近似转换有适用误差，不做精密测绘。
- 酒店：AIGOHOTEL；真实门店与品牌参考分开，品牌参考不是可订门店。查询参考价格不保证实际库存。
- 联网：百炼WebSearch MCP，保留当次摘要和URL；标题含“官网”不代表该站已被确认是官网，摘要不等于已逐页读取网页，也不保证最新。
- 天气：本机stdio天气MCP与Open-Meteo只读查询；高德服务也已配置。腾讯地图本轮曾日配额耗尽，未计为成功证据。

## 三组不同的数量

342是原文城市选择器静态条目数，79/30/44分别是机场、票价城市、坐标辅助表条目数，39才是当前固定攻略库实际城市数。不能相加，也不能把选择器数量写成知识库覆盖数量。
