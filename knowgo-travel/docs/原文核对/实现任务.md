# 知行完整实现任务

**Goal:** 在桌面knowgo-travel保留旧learn，将正式业务接成完整旅行应用。
**Architecture:** app/full独立领域模块，复用已有真实MCP客户端；七步create_agent使用PG checkpoint，ORM保存账户/会话/消息/卡片/清单；确定性候选、预算、正文渲染与模型内容生成分工。数据检索单独异步封装。
**Tech Stack:** FastAPI、LangChain/LangGraph、SQLAlchemy/asyncpg、PostgreSQL、Redis、Chroma、DashScope、DeepEval。

- [x] app/full/domain.py：严格需求、统一日期拓扑、四时段结构、逐项预算。tests/test_full_domain.py覆盖往返、本地、多城、重复节点、一日0晚与不等晚房价。
- [x] app/full/database.py、security.py：业务表/唯一清单/卡片版本、JWT与bcrypt、会话归属；测试401、越权404、删除、伪造、并发重复注册。
- [x] app/full/capabilities.py：四能力按段并行、航班票价融合、品牌兜底、稳定身份、持久候选、过期与幂等提交；空段和单服务失败独立保留。
- [x] app/full/knowledge.py、scripts/ingest_guides.py：真实攻略来源、Chroma父子索引、jieba BM25/RRF、查询优化/LLM重排、Redis版本缓存；城市隔离与冷/热评测。
- [x] app/full/destination.py：classifier/Send并行攻略天气/reducer/合成；验证真实框架执行和分支降级。
- [x] app/full/agent.py、workflow.py：七步工具/中间件、确认、修订回退、记忆、express、直查与闲聊；真实模型完整链路验收。
- [x] app/full/api.py、events.py：正式REST与八类SSE、卡片提交续跑、历史重放、断连取消、持久化后done；接口测试。
- [x] app/full/plans.py、quality.py：严格结构化生成和有限重试、约束来源、地图增强、稳定清单与后台DeepEval；不使用占位填充骗过校验。
- [x] app/static/travel.html：登录、会话、需求表单、聊天、四类卡片、历史、地图清单与修改；真实浏览器/HTTP端到端。
- [x] 扩展Docker Redis，完整回归/重载恢复/多用户隔离/真实服务与独立评测；更新README、简历指标报告。

每一步先写关键边界验证再实现；测试只对照真实业务口径。用户授权本会话连续执行，不停在计划确认。
