## 已接通的功能

- 单create_agent＋StepConfig动态中间件：收集需求、推荐/确认目的地、交通、住宿、餐饮、结构化行程、预算。目的地内部使用真实StateGraph、classifier/Send并行攻略与天气/reducer合流。
- 单城往返、多城、本地、一日、目的地含出发地、自动选城；统一日期拓扑、逐站入住窗口与返程。N天按N−1晚核算，一日不造酒店。
- 12306高铁/动车、Variflight航班时刻与按航班号融合的经济舱参考价、高德自驾、AIGOHOTEL门店/明确标注的品牌参考；四类卡片支持手选与自动选择、多段并行、多交通偏好按顺序降级。上海/北京/成都支持多机场组合。未知余票、未知价格、服务失败分别保留，不冒充可订或已订。
- JWT、bcrypt、SQLAlchemy异步业务表、资源所有权、会话历史与软删除；PG Checkpointer恢复状态，PGStore按用户保存5类跨会话记忆，过敏信息进入禁忌约束。
- revision确认守卫、回退级联清理、持久卡片、过期拒绝、重复提交幂等、回执与Checkpoint之间的故障恢复；旧行程明确标为旧版本。
- Chroma + DashScope text-embedding-v2；父1000/子200分块、中文BM25+dense/RRF、MultiQuery/HyDE/rewrite/hybrid、Qwen重排、父块恢复、长上下文重排、Redis版本缓存与城市隔离。百炼联网搜索补充开放/预约等时效信息，结果保留来源和时效说明。
- role/content/code SSE、闲聊真实token流、业务进度/卡片/清单事件、有界队列、断连取消与数据库清理；同会话PG写锁串行，不同会话独立。
- 模型提交严格schema，代码校验城市/天数/时序/来源并渲染；预算逐段逐站复算、查询价与估算拆开、按间夜和人数计价；地图含真实高德POI、名称匹配、照片、步行/驾车路线和坐标转换。地点不匹配或服务失败时不伪造坐标。
- DeepEval QwenJudge对完整性、需求匹配、真实性异步评分告警，离线复用同一规则；结果不是事实准确率，低分不隐藏。

## 本机启动

本机uv、Python、Docker CLI、Colima、Node已配置。PostgreSQL与Redis使用Docker；应用使用uv虚拟环境，Chroma索引持久化在本地。

```bash
cd /Users/jarvis/Desktop/大模型开发/knowgo-travel
bash scripts/start-full.sh
```

启动脚本检查Docker引擎、等待PG/Redis健康、同步冻结依赖、安装缺失的12306运行包、应用始发/上车日期补丁，默认8001。需要其他端口：`KNOWGO_PORT=8002 bash scripts/start-full.sh`。Docker默认上下文为本机已配置的`colima-knowgo`；其他机器可用`DOCKER_CONTEXT=default`指定引擎。

配置保存在本机`.env`和`外部服务配置.env`，后者覆盖前者。不要删除原PG卷；不要执行`down -v`。JWT签名材料在`data/.jwt_secret`首次生成并持久化；交付包不携带它或任何真实凭证。

新机器复制`.env.example`为`.env`并配置PG密码和各服务Key。已有71份攻略JSON可直接构建索引：

```bash
PYTHONPATH=. uv run --frozen python scripts/build_full_rag.py
uv run --frozen pytest -q
```

索引重建会调用真实embedding接口。完整原始CSV的来源与SHA见`docs/数据来源.md`；交付包包含清洗后的有来源正文与已建索引，原始83MB CSV不重复打包。

## 使用与复盘

右侧表单支持自动代选；取消勾选则先确认目的地，再逐段选择交通和逐站选择住宿。可按勾选顺序增加备用交通，并多选餐饮偏好。会话可重命名、归档/恢复。会话中可修改需求、查看进度或明确要求长期记住偏好。“我的行程”查看地图、预算、来源；“我的偏好”可编辑5类记忆。历史卡片会回放提交态；断连后可从数据库恢复活动卡片。

代码入口：`app/full/api.py` → `workflow.py` → `agent.py`/`capabilities.py` → `plans.py`。外部服务在`app/services/remote.py`，RAG在`app/full/knowledge.py`，在线评测在`quality.py`。复盘与61题清单仍保留，助手验证通过不等于用户已经亲自实践或掌握。

## 数据与验收边界

当前71份公开历史攻略，覆盖39城、966条去重景点活动描述、404025字元，654父块/3120子块。数据源已知最后编辑年代至2016，**不是现时营业信息**；342城是选择器数量，79城机场辅助表也不是攻略覆盖率。联网搜索当次摘要仍可能过时或互相矛盾，出行细节应核对官方公告。

酒店品牌参考不承诺城市存在可订门店；未知票价不填0；儿童交通暂按成人参考价并注明。油费按0.65元/公里估算并加入已返回过路费，停车等另计，不能当完整车辆报价。报价是查询时参考价。腾讯地图曾返回日配额耗尽，正式驾车使用已真实验证的高德；不声称腾讯查询成功。
